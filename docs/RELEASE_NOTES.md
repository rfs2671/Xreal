Ultra XR for Pixel + XREAL Air 2 Ultra.

**Install:** download `ultra-xr-*.apk` on the phone, open it and allow the install. Plug the glasses in, open Ultra XR, and run the one-minute hardware check it offers.

**Status:** run on a Pixel 10 Pro XL with the glasses: a WebXR game (Ball shooter) was played with the phone as a touchpad, the scene staying in place while walking, as one flat picture for both eyes. The glasses do not hold their 3D mode from this phone, so there is no depth. The home view in the glasses and the steadier hand ray have been checked on the emulator and from a recording, not yet through the glasses. `docs/ACCEPTANCE.md` has the full table of what was seen where.

`hello_xr-*.apk` is the Khronos OpenXR sample app, included as a known-good third-party app to try the runtime with.
